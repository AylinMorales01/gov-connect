# Integración DuckDB

DuckDB será utilizado como motor analítico.

No reemplaza SQL Server.

---

## SQL Server

Almacenamiento transaccional.

Operaciones diarias.

---

## DuckDB

Consultas analíticas.

KPIs.

Comparativos.

Tendencias.

Reportes.

---

    SQL Server
    ↓
    Proceso de sincronización

    Dashboard
